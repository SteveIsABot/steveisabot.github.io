Team Full-Stack Website

Features That I Conributed To

  • Form handling
  • Login/Registering System
  • CRUD methods for database
  • Security based on user access level
  • Data handling/storgae solution
  • Data transfer between front-end and back-end

Form handling & Registering

First check if feilds are empty. Uses regex to check each feild meets certain criteria. Checks if email and username already exisits in database. Creates a new user and saves it to database. Sends mail to email to confirm email.

Login System

First check if feilds are empty. Uses regex to check each feild meets certain criteria. Uses a one time password to fully login the user. Logs user in, with certain access depending on there 'role'. The user can also logout once they have logged in.

CRUD Methods

The users can create a complaint. The admins can edit, update and delete complaint. These complaints contain a location, date, image and description.

Security Level Access

Based on role of the currently logged in user they are allowed certain access. If role is user they can only access the creation of complaints and home page. If role is admin they can access the viewing of all complaints, and the editing and deletion of said complaints. If user role trys to access the admin role they get denied.

Data handling/storage

All data is handled using SQLAlchemy, and so is stored locally. Images are stored seperately, and the location of the images is stored with the complaint in a complaint table. Images are stored locally in a file, this way it complies with modern database protocols.

Data transfer between front-end and back-end

Front-end sends data using JWT in a JSON format. Back-end receives data and handles it based on request. Back-end sends data via JWT and front-end then update based off feedback.
